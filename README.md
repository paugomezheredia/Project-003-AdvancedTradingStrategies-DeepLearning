# Project-003-AdvancedTradingStrategies-DeepLearning

## 📈 Systematic Trading Strategy using Deep Learning

A deep learning–based framework for generating directional trading signals (long, short, hold) using architectures like MLP, CNN, and LSTM.
This project integrates MLflow tracking, data preprocessing, feature engineering, and class imbalance handling to deliver robust, production-ready models.


## ⚙️ Project Setup

### 1️⃣ Create Virtual Environment

To execute this project correctly we need to create a virtual envitonment (venv) and use the versions and libraries stated in the 'requirements.txt'. Use the following steps to do so:

- Create your venv locally:

    - for Mac / Linux users: python3 -m venv venv

    - for Windows users: py -m venv venv

### 2️⃣ Activate Environment

- Activate your venv:

    - for Mac / Linux users: source venv/bin/activate

    - for Windows users: .\venv\Scripts\Activate

💡 Tip: When activated, you’ll see '(venv)' at the beginning of your terminal line, which means you’re now working inside the virtual environment.

### 3️⃣ Install Dependencies

- Install 'requirements.txt':

    - for all OS users: pip install -r requirements.txt

## 🧠 Run the Experiment

### 4️⃣ Launch MLflow Tracking UI (optional but recommended 🚀)

- Open a terminal and run:

    - for Mac / Linux users: mlflow ui
 
- Go to :
    - [for Mac / Linux users: mlflow ui] (http://localhost:5000/)
 
You’ll be able to track your experiments, metrics, parameters, and models visually.


### 5️⃣ Run Training Script

    
- Run Project from terminal:

    - for Mac / Linux users: python main.py

    - for Windows users: py main.py

As an outpur we obtain the metrics of the project's final results.
